# North Bengaluru Corridors

Interactive map of North Bengaluru real-estate growth corridors (₹10–20 L/gunta focus), with Google-Maps-style place search, a mobile bottom sheet, and directions.

Static site — a single `index.html`, no build step. Deploy on Vercel as a static project (framework preset: **Other**, no build command).

Zone boundaries and road alignments are indicative, not survey or master-plan accurate.
